Other XMP names</br>
For those, you will need to include the complete prefix :

XMP-xmp:CreateDate</br>
XMP-xmp:ModifyDate</br>
XMP-xmp:CreatorTool</br>
XMP-xmp:Rating</br>
XMP-photoshop:City</br>
XMP-photoshop:Country</br>
XMP-photoshop:Credit</br>
XMP-photoshop:Headline</br>
XMP-photoshop:Instructions</br>
XMP-iptcCore:Keywords</br>

Examples :

✅ Creator → XMP-dc:Creator</br>
✅ Rights → XMP-dc:Rights</br>
✅ XMP-xmp:Rating → XMP-xmp:Rating</br>
✅ XMP-photoshop:City → XMP-photoshop:City</br>

❌ Comment (not a standard XMP type)</br>
❌ Azerty (random type)</br>
❌ Author (use Creator instead)</br>
